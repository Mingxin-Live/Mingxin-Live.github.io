## 二、质量审查发现

### 1. 结构性检查（599 题全量，脚本核验）
- id 唯一：通过（g1..g599，无重复）。
- 答案索引 a：全部为 0–3 的整数，且解析 e 均以"正确项：<o[a] 前缀>"开头 —— **索引与解析一致，无答案错位**。但正确性仅是"选项=原文句子"的机械一致，不代表题目可用。
- 选项数：均为 4。存在少量选项为句子截断、含 OCR 空格（如"标 准形式""解 决"）。

### 2. 内容质量（根本性缺陷，599/599 = 100%）
- **题干模板单一**：全部为"关于「X」，下列说法正确的是？"，无情境。
- **正确项=教材原句照抄**：正确选项往往明显比干扰项"通顺、像定义"，一眼可辨，无鉴别度。
- **干扰项=同章节随机句子**：与题干无语义关联，四个选项经常互不相干，谈不上互斥性设计。
- **解析 100% 模板化**：599/599 均含"本题基于教材正文要点整理，错误选项为同章节其他要点内容，注意区分概念边界"，无任何解释力。
- 知识点覆盖随机（取决于句子抽取），不覆盖计算题、场景决策题。

### 3. 具体错误示例（旧 GBANK，已随整体重建废弃，此处仅存档）
- g1 正确项"安全的重要性经常被提及，但我们并非总能理解其中的缘由"——伪命题式正确项，无考查价值。
- g2 正确项"安全很重要，是因为当有人试图窃取……"——选项内多空格、口语残句；干扰项为 BCP/治理内容，与题干"安全"主题完全无关。
- 大量题干 f 字段带悬挂空格（如"1 安全 "）；两个选项含有 OCR 噪声空格。

结论：旧 GBANK 不是"部分错题"问题，而是生成方法问题 → **全量重写**（不小于原量 60%，即 ≥360 题）。

## 三、重建结果

### data/gbank_v2.json（新版章节题库）
- **360 题**（原 599 的 60.1%），8 大域 **45×8 均衡分布**，21 章考点覆盖（f 字段对齐 cissp-chapters.json 章名）。
- 保持原字段结构：{id, d, w, q, o[4], a(0–3), e, f, v:[]}。
- 风格：情境化题干（场景+角色+决策点）、四选项互斥且合理（含常见误区选项）、考概念辨析/最佳实践/场景决策；解析"为什么对 + 其他选项为什么错 + 教材章节出处"，全部中文。
- 含计算题（ALE/SLE/ARO、RTO/RPO 定量题）。

### data/exambank_v2.json（新版模考题库）
- **102 题**，按 CISSP 考试域权重分布：域1 15、域2 10、域3 13、域4 13、域5 13、域6 12、域7 15、域8 11。
- 结构与 gbank_v2 相同（id: ex1..ex102），题目与章节题库**零重复**（含跨库 id 与题干查重）。
- 风格更偏真题：长情境（董事会问询、事件处置序列、供应链应急、云上 IAM 治理等）与"最佳方案"型四选。

### 验证（python，脚本核验通过）
- 两个 JSON 可正常 json.load；
- 所有 a ∈ {0,1,2,3}，o 长度=4 且四选项文本互不相同；
- gbank_v2 内部、exambank_v2 内部、两库之间 id 均无重复；
- 解析与正确项人工交叉复核（编写时逐题构造"正确项解释+干扰项排除"），无索引与解析矛盾。
