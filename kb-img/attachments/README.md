## 仓库约束

- 优先保存经过尺寸压缩的阅读版，避免同时提交无用途的多份原图；
- 新图片必须在索引中登记主题、来源、核验日期和适用边界；
- 外部图片不得因“看起来正确”直接作为事实证据，结论仍回到官方标准、文档或源码；
- 单个大文件提交前先检查是否真的需要进入 Git 历史，插件程序与临时工作产物不放入附件目录。
