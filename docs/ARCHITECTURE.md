# 系统架构

## 分层

```
┌────────────────────────────────────────────────┐
│  UI 层（单文件 HTML，全部内联）                   │
│  Hero / 阶段卡片 / 岗位方块 / 知识卡片 / 笔记博客  │
├────────────────────────────────────────────────┤
│  交互层                                          │
│  switchTab 路由 · 弹层 · 沉浸阅读(header收缩/回顶)│
├────────────────────────────────────────────────┤
│  业务逻辑                                        │
│  Adaptive Study Planner（动态时间计算）           │
│  Progress Engine（统一进度计算）                  │
│  考试训练器（模考/章节测验/错题/复习 四模式）       │
│  游戏化（积分/等级/成就）                         │
├────────────────────────────────────────────────┤
│  数据访问                                        │
│  KBAdapter（Embedded/LocalFile/IMA 预留）        │
│  localStorage（key: wb_sec_workbench_v1）        │
├────────────────────────────────────────────────┤
│  内容管道（构建期脚本 build_content.js）           │
│  OSG 第9版中文 + 第10版英文 → data/cissp-content.json
└────────────────────────────────────────────────┘
```

## 核心数据模型

| 实体 | 说明 |
|------|------|
| StudyPhase (PHASES_V5) | 8 阶段（按教材 8 域），每阶段含章节区间与学习量 |
| StudyTask | 每日任务：下一未学章节（nextLesson） |
| LearningRecord (S.records) | `{日期: [{minutes, ch, ts}]}` 进度引擎输入 |
| CISSPDomain / Chapter | 教材 21 章索引（SYLLABUS） |
| Question / Exam | 题库 150 种子 × 变式 ≈ 1800 组合 |
| KnowledgeItem | 知识库条目（教材章节 + AI 卡片 + 本地导入） |
| Note / BlogPost | Markdown 笔记与博客（draft/published） |
| SkillProgress (S.skillLv) | 技能掌握度（0-5） |

## 动态学习计划算法

```
输入：阶段章节数 × 每章 3 学习日 × 每日分钟 = 阶段总需求分钟
进度 = 已学分钟(按阶段起始日过滤) / 总需求分钟
速率 = max(最近 7 天日均分钟, 每日目标)
预计完成 = 今天 + 剩余分钟 / 速率
延期 = 预计完成 − 计划完成（>4 天红 / 3-4 黄 / ≤2 正常）
```

任何学习记录写入后自动触发重算，用户无需手工改日期。

## 内容管道

`build_content.js` 提取教材章节结构（处理 CRLF、目录去重、OCR 噪声过滤），
产出 `data/cissp-content.json` 与内嵌 `SYLLABUS` 常量（21 章 × 中文/英文标题 × 域 × 小节索引）。
